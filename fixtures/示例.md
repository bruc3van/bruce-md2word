# Markdown 导出示例

这是一份由 **bruce-md2word** 生成的可编辑 Word 文档。支持中文、*强调*、~~删除线~~、`行内代码`和[链接](https://example.com)。

## 列表与引用

3. 从指定编号开始
4. 第二项
   - 嵌套的无序列表
   - 保留层级

> 引用内容保留独立的段落样式。
>
> 第二段引用内容。

## 表格

| 能力 | 说明 |
| :--- | :--- |
| 输入 | Markdown 文件或正文 |
| 输出 | 项目目录中的 DOCX 文件 |
| 图片 | PNG、JPEG、GIF、BMP |

## 代码

```typescript
const result = await tools.word_export({
  source: { kind: 'markdown', text: '# 你好，Word' },
  fileName: '报告.docx',
});
```
