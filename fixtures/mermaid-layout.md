# Mermaid 正常案例测试

本文档用于验证 `dsh-md2word`（word_export）的 Mermaid 转图片能力。共六类图，每张图前给出编号、测试目的与预期效果。

覆盖要点：中文节点与中文连线标签、全角标点、中英数字版本号混排、长标签与 `<br>` 换行、分支汇合与子图、时序图多参与者与返回消息、类图中文属性方法、ER 图中文字段名（无字段注释）、XY 图中文标题与坐标轴、一张较宽的横向流程图，以及普通 Markdown 与图表混排。

---

## 一、流程图（flowchart）

**编号：** M1
**测试目的：** 验证中文节点、中文连线标签、全角标点、中英数字版本号混排、长标签、`<br>` 显式换行、分支、汇合与子图。
**预期效果：** 渲染为 PNG 流程图；节点内出现中文与 `User Request v1.2.0` 等混排文本；带 `<br>` 的标签分成两行；出现判断分支与汇合节点；`处理模块（Stage 1）` 子图边框完整包裹其内部节点。

```mermaid
flowchart TD
    A["用户请求<br>User Request v1.2.0"] --> B{"参数校验<br>（第 1 步）"}
    B -- "校验失败：缺少必填项" --> C["返回错误码 400<br>Bad Request"]
    B -- "校验通过（OK）" --> D["进入处理流程"]
    C --> Z["结束（End）"]

    subgraph SG1["处理模块（Stage 1）"]
        D --> E["加载配置 config.yaml<br>读取超时 30 秒"]
        E --> F{"是否需要缓存？"}
        F -- "是：命中 Redis 7.2" --> G["读取缓存数据"]
        F -- "否：直接查询" --> H["查询数据库<br>MySQL 8.0.36"]
        G --> I["合并结果（Merge）"]
        H --> I
    end

    I --> J["这是一个很长的节点标签：用于测试在横向空间不足时文本如何自动换行与缩放后的可读性 v3.14.159"]
    J --> Z
```

## 二、时序图（sequenceDiagram）

**编号：** M2
**测试目的：** 验证多个参与者、中文参与者别名、请求消息与返回消息（`->>` / `-->>`）、中文消息标签与全角标点。
**预期效果：** 渲染为 PNG 时序图；顶部出现 4 个参与者（客户端、网关、订单服务、数据库）；箭头方向一致；返回消息用虚线箭头表示；消息文本为中文。

```mermaid
sequenceDiagram
    participant C as 客户端 Client
    participant G as API 网关（Gateway）
    participant S as 订单服务 Order Service v2.1.0
    participant D as 数据库 MySQL 8.0

    C->>G: 提交订单 Order #10086
    G->>S: 转发请求（含 Token）
    S->>D: 查询库存 SKU-2048
    D-->>S: 返回可用库存 12 件
    S->>D: 写入订单记录
    D-->>S: 写入成功（commit）
    S-->>G: 下单成功，订单号 20240921
    G-->>C: 返回结果：下单成功！
```

## 三、状态图（stateDiagram）

**编号：** M3
**测试目的：** 验证状态图的中文状态名、中文转移标签、起始与结束状态、带版本号的转移说明。
**预期效果：** 渲染为 PNG 状态图；出现 `[*]` 起始点与结束点；状态名与转移标签均为中文；`审核通过（Admin）` 等标签显示在箭头上。

```mermaid
stateDiagram-v2
    [*] --> 待审核
    待审核 --> 已通过: 审核通过（Admin）
    待审核 --> 已驳回: 审核不通过

    待发货 --> 已发货: 出库完成（Warehouse）
    已发货 --> 已完成: 用户确认收货
    已驳回 --> [*]
    已完成 --> [*]
```

## 四、类图（classDiagram）

**编号：** M4
**测试目的：** 验证类图中的中文类名、中文属性名、中文方法名与参数、可见性符号与继承关系。
**预期效果：** 渲染为 PNG 类图；`用户账户`、`订单管理` 等类框内出现中文属性与方法签名；`<|--` 继承箭头正确连接；关联关系带中文标签。

```mermaid
classDiagram
    class 用户账户 {
        +字符串 用户名
        +字符串 手机号
        +整数 会员等级
        +登录(密码) 布尔
        +修改密码(旧密码, 新密码) 布尔
    }

    class 普通用户 {
        +整数 积分
        +下单(商品编号, 数量) 订单
    }

    class 订单管理 {
        +列表 订单列表
        +创建订单(用户编号) 订单
        +取消订单(订单号) 布尔
    }

    用户账户 <|-- 普通用户 : 继承（Inheritance）
    普通用户 --> 订单管理 : 使用 v1.4.0
```

## 五、ER 图（erDiagram）

**编号：** M5
**测试目的：** 验证 ER 图中的中文实体名、中文字段名、中文关系标签、主键标记；**不使用字段注释**（字段后不加引号注释）。
**预期效果：** 渲染为 PNG ER 图；实体 `用户`、`订单`、`订单明细` 内出现中文字段名与 `int`/`string` 类型；关系连线标签为中文；`PK` 标记出现在主键字段后。

```mermaid
erDiagram
    用户 ||--o{ 订单 : "下单"
    订单 ||--|{ 订单明细 : "包含"
    商品 ||--o{ 订单明细 : "被购买"

    用户 {
        int 用户编号 PK
        string 用户名
        string 手机号
        int 会员等级
    }

    订单 {
        int 订单编号 PK
        int 用户编号
        string 订单状态
        string 创建时间
    }

    订单明细 {
        int 明细编号 PK
        int 订单编号
        int 商品编号
        int 数量
    }

    商品 {
        int 商品编号 PK
        string 商品名称
        int 单价
    }
```
